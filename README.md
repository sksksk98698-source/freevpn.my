## 📖 项目简介 (Overview)

**FreeVPN.my** 是一套面向全球跨境网络工程、企业级跨境办公、外服极客电竞与海外生产力 AI 加速的独立评测与专线架构知识库。

项目依托 **Astro 静态生成引擎** 与 **Keystatic Git-based CMS** 深度定制，构建了 **277 个完全预渲染的纯静态高性能页面**。全站彻底告别传统测速网站的虚假并发跑分与商业水军套路，以位于上海、广州、成都核心 POP 入口机房的自动化真实探针为基准，对全网 **42 家主流机场服务商** 实施连续 500 次 ICMP 探针抗丢包压测、单线程 curl / iperf3 晚高峰极限吞吐检测，以及主流海外流媒体与 AI 工具原生住宅 IP 解锁核验。

## 🛠️ 本地运行与开发指南 (Getting Started)

### 前置环境需求
- **Node.js**: `>= 22.12.0`（建议使用 Node.js 24 LTS）
- **包管理器**: `pnpm`（推荐 `pnpm 9+`）

### 1. 克隆并安装依赖
```bash
git clone https://github.com/sksksk98698-source/freevpn.my.git
cd freevpn.my
pnpm install
```

### 2. 启动本地开发服务
```bash
pnpm dev
```
启动后访问：
- **前台测试站点**：`http://localhost:4321`
- **Keystatic 本地内容管理面板**：`http://localhost:4321/keystatic`

### 3. 类型检查与单元测试
```bash
# 验证 Astro 组件类型与所有 Content Collections 数据合法性
pnpm check

# 运行 Vitest 完整单元测试套件（84 个测试用例，100% 通过）
pnpm test
```

### 4. 生产环境全静态构建
```bash
# 执行完整 SSG 预渲染编译
pnpm build

# 运行顶级预防性技术 SEO / GEO 深度审计
node scripts/audit-seo.mjs

# 本地预览编译后的静态站点
pnpm preview
```
